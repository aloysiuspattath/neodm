🌐 Browser Integration

Auto-capture downloads directly from Chrome, Edge, and Firefox

  1. Open chrome://extensions in your browser.
  2. Enable Developer mode in the top-right toggle.
  3. Click Load unpacked and select the directory:
    d:\new projects\ifd\extension
  4. The NeoDM extension icon will appear in your browser toolbar with automatic 1-click capture!
